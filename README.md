# Geekly

Geekly — мобильное приложение для ведения личной коллекции фильмов, сериалов, аниме, манги, книг и видеоигр. Можно добавлять найденные материалы или создавать записи вручную, отмечать прогресс и собирать статистику по своей библиотеке.

## Возможности

- Поиск и карточки с описаниями, постерами и другими сведениями о произведениях.
- Личные коллекции по шести категориям: фильмы, сериалы, аниме, манга, книги и игры.
- Создание и редактирование записей, статусы просмотра/чтения/игры, избранное, оценки и папки.
- Фильтрация и сортировка коллекций, настройка статусов и порядка категорий.
- Дашборд с прогрессом и аналитикой коллекции.
- Достижения, включая скрытые.
- Темы и настройки интерфейса, звука, вибрации и уведомлений.
- Локальное хранение, добавление собственных изображений, экспорт и импорт резервной копии в ZIP.

## Технологии

- React Native и Expo SDK 55
- JavaScript, React 19
- React Navigation
- Zustand
- SQLite (`react-native-quick-sqlite`)
- Expo File System, Image Picker, Document Picker и Sharing
- Интеграции с TMDB, RAWG, Google Books и Shikimori

## Запуск для разработки

### Требования

- Node.js и npm
- Android Studio и Android SDK для локальной сборки Android
- Учётная запись Expo/EAS — только для сборки через EAS

В проекте используются нативные модули, поэтому для разработки на устройстве нужна development build, а не только Expo Go.

1. Установите зависимости:

   ```sh
   npm install
   ```

2. При необходимости создайте локальный `.env` на основе `.env.example` и укажите ключи API. Shikimori использует публичный GraphQL API без ключа.

   ```powershell
   Copy-Item .env.example .env
   ```

   Для локальной работы поиска используются `EXPO_PUBLIC_TMDB_API_KEY`, `EXPO_PUBLIC_RAWG_API_KEY` и `EXPO_PUBLIC_GOOGLE_BOOKS_KEY`. Получите собственные ключи у соответствующих провайдеров. Переменную `EXPO_PUBLIC_MY_SUPER_PUPER_SECRET_KEY_WORD` из примера не настраивайте: это дополнительное кодовое слово для подтверждения удаления данных, а не ключ API. **Любая переменная с префиксом `EXPO_PUBLIC_` встраивается в приложение и не является секретом**; не помещайте туда пароли или ключи с привилегиями, которые нельзя раскрывать, и ограничивайте API-ключи средствами провайдера.

3. Создайте и запустите Android development build:

   ```sh
   npm run android
   ```

   Либо запустите Metro для уже установленной development build:

   ```sh
   npm start
   ```

## Сборка Android

Настроены профили EAS `preview` (APK) и `production`. Команда проекта для preview-сборки:

```sh
npm run build
```

Для неё нужны настроенный EAS CLI и доступ к проекту Expo.

## Данные и конфиденциальность

Коллекция и настройки хранятся локально на устройстве в SQLite; аккаунта и облачной синхронизации в проекте нет. При поиске приложение обращается к внешним каталогам. ZIP-резервная копия может содержать записи коллекции и добавленные пользователем изображения — храните её как личные данные.

## Источники данных

- [The Movie Database (TMDB)](https://www.themoviedb.org/)
- [RAWG](https://rawg.io/)
- [Google Books API](https://developers.google.com/books)
- [Shikimori](https://shikimori.one/)

## Структура проекта

- `screens/`, `components/` — экраны и интерфейсные компоненты.
- `hooks/` — логика экранов, поиска, данных и настроек.
- `services/` — клиенты внешних каталогов.
- `store/`, `utils/sqliteStorage.js` — состояние приложения и его локальное сохранение.
- `utils/achievements/` — расчёт и описания достижений.
- `constants/`, `theme/` — справочники, статусы и темы оформления.
- `assets/` — изображения, значки, анимации и звуки.
